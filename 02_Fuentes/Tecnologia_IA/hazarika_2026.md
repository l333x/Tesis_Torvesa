## Resumen (de la base de datos, no de la lectura)
This research paper presents Knowledge Buddy, a web-based integrated student learning platform that consolidates six essential study functions into a single authenticated workspace: AI Buddy (GPT-4o conversational assistant with document upload and persistent chat history), QuizForge (adaptive AI-driven quiz generation), Knowledge Vault (academic book discovery via Open Library API), KnowledgeTube (focused educational video search using YouTube Data API v3), Knowledge Stack (typed personal resource manager), and a Student Dashboard aggregating cross-module activity. The system is implemented using React 19 with Vite 6 on the frontend, Node.js 20 LTS with Express 5 on the backend, and a normalized thirteen-table MySQL 8 schema. Security features include bcrypt password hashing, OTP-based email verification, HTTP-only cookie sessions, and endpoint rate limiting. Forty test cases across unit, integration, and system levels confirmed correct behavior for all major user journeys. This work demonstrates that a multi-module, AI-integrated student platform can be deployed using open-source tooling and commercially available APIs at a cost accessible to educational institutions.
