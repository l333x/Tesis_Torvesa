# Una metodología para la gestión del conocimiento basada en arquitectura de procesos para una PyME constructora (diseño preliminar)

## Qué respalda
Caso de una pyme constructora mexicana con más de 30 años: cada persona lleva su propio control, nadie sabe quién tiene qué información, y se pierde tiempo buscándola (p. 616). La propuesta tiene 4 fases. En la fase 2 se crea una base de conocimientos que reúna lo que ya existe y lo que se vaya generando (p. 623). En la fase 4 esa base se mantiene y se amplía con el tiempo (p. 624).

## Cita textual
> «la creación de una base de conocimientos para almacenar y dar uso, de forma ordenada, a todo el conocimiento y la información que ya existe en la organización, así como lo que se va creando conforme pasa el tiempo» (p. 623)

## Cómo se usa en la tesis
Es el antecedente latinoamericano más cercano a Torvesa: una pyme constructora con el conocimiento disperso entre personas. Cap. 2, como antecedente, y Cap. 5: respalda que la bóveda se diseñe junto con el proceso comercial (primero se entiende el proceso, luego se crea la base y después se mantiene). La descripción de la p. 616 («El control lo lleva cada persona por separado y estas no saben específicamente con qué información cuenta cada quien ni quien la tiene») sirve para el planteamiento del problema.
