# Data controls in the OpenAI platform

## Qué respalda
Condiciones de datos de la API de OpenAI, al 25-oct-2026:

- Lo que se envía a la API **no se usa para entrenar** sus modelos, salvo que el cliente acepte compartirlo.
- Por defecto se guardan **registros de monitoreo de abuso hasta 30 días**.
- Solo los clientes **aprobados** pueden excluir su contenido de esos registros.

## Cita textual
> «data sent to the OpenAI API is not used to train or improve OpenAI models» (Página web)

> «By default, abuse monitoring logs are generated for all API feature usage and retained for up to 30 days» (Página web)

## Cómo se usa en la tesis
Inventario de herramientas (S2-T11), componente **LLM**, criterio de la **LOPDP**. Comparación con Anthropic: los dos dicen que no entrenan con los datos de la API. La diferencia está en la retención: OpenAI guarda registros de abuso hasta 30 días por defecto, y Anthropic dice que por defecto no guarda el contenido de las conversaciones, salvo en algunos modelos.
