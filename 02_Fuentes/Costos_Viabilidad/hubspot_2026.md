# HubSpot Data Processing Agreement

## Qué respalda
HubSpot tiene un **acuerdo de tratamiento de datos (DPA)** que ya forma parte de sus términos para clientes: no hay que pedirlo aparte. Los datos de clientes pueden procesarse en Estados Unidos, y para esas transferencias se aplican **cláusulas contractuales tipo**. Página actualizada el 16-sep-2026.

*DPA: el contrato que fija cómo un proveedor trata los datos personales por cuenta del cliente; en la LOPDP, el proveedor es el «encargado» del tratamiento.*
