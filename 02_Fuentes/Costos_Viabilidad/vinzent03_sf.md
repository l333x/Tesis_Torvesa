# Obsidian Git (README)

## Qué respalda
README oficial del plugin: en el móvil Git es «very unstable», puede colgarse al clonar o hacer pull según la RAM, no tiene SSH, el tamaño del repositorio está limitado por la memoria, y el autor recomienda otros servicios de sincronización en el móvil.

## Cita textual
> «The Git implementation on mobile is very unstable!» (README, sección sobre el móvil)

## Cómo se usa en la tesis
Cap. 5, herramientas y riesgos (A34). Es más fuerte que «Git puede ser lento»: el mantenedor no lo recomienda en el móvil. Refuerza usar Obsidian Sync (u otra sincronización) en los teléfonos de los vendedores.

Consultado el 21-oct-2026. Es documentación técnica, no un artículo; sirve para un dato técnico concreto. Diego decide la sincronización en el inventario de herramientas.
